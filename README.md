# Desktop-Fuchs 🦊

Kleine Füchse für deinen Windows-Desktop: Sie laufen über den Bildschirm, sitzen auf Fenstern, folgen deiner Maus und lassen sich hochheben. Kostenlos.

## Herunterladen

**[⬇ Desktop-Fuchs.exe herunterladen](https://github.com/obimokenobix/desktop-fuchs/raw/main/Desktop-Fuchs.exe)** (Windows 64-Bit, ca. 10 MB)

Webseite: https://obimokenobix.github.io/desktop-fuchs/

## So geht's

1. `Desktop-Fuchs.exe` herunterladen.
2. Doppelklick darauf – die Füchse laufen sofort los, ohne Installation und ohne Python.
3. Zeigt Windows „Der Computer wurde durch Windows geschützt“: **Weitere Informationen** → **Trotzdem ausführen**.

## Bedienung

- **Klick** = streicheln, **Doppelklick** = Salto
- **Ziehen** = hochheben und werfen
- **Rechtsklick** = Menü mit Einstellungen (Farben, Größe, Verhalten, neue Füchse, Mit Windows starten, Beenden)

Vier Sorten: Rotfuchs, Polarfuchs, Silberfuchs und Fennek – plus eigene Sorten mit eigenen Farben.
